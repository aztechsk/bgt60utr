# BGT60UTR

Driver for the Infineon BGT60UTR radar sensor.

The module provides low-level access to the BGT60UTR device over SPI. It implements register read/write operations, chip identification checking, and software reset.

## Features

- SPI register read and write
- Chip identification check
- Software reset
- Integration with the project SPI HAL

## Files

- `bgt60utr.c` — driver implementation
- `bgt60utr.h` — public interface, device descriptor and register definitions
